Things to try
  1. Find a blouse. Wardrobe, then Tops, then Blouses. Then try the same in the outfit builder and capsule editor.
  2. Narrow outfits to a shirt and boots. Filters, Pieces, Tops, Shirts. Pick one, go Back, then Shoes, Boots.
  3. Mix filters. Add a tag and a capsule. Watch the count in "See N outfits" and the empty state when it hits nought.
  4. Heart a few outfits, then open Faves from the bar and filter by level.
  5. Add a hat to an outfit. Tap the + on a card. Hats has two types, Jewellery has one.
  6. Switch design A, B, C and repeat any of the above.
