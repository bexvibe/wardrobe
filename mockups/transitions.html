Transition options

Everything here is live: tap it. Open it on your phone for the real feel. Photos are the demo ones, so a rebuild reloads real images, as the app does. “Current” reproduces how the app behaves today, so you can compare each option against it.

1 · Selecting a piece

Tap tiles and chips. Current rebuilds every tile on each tap with a 1px→2px border, so the selected state snaps and photos reload. Option A updates the existing tiles in place so the border fades. Option B swaps instantly, with no flash but also no animation.

2 · Opening an outfit

Tap any card. Scroll the phone first to see how each one behaves from mid-list. The header at the top is a sticky filter row.
