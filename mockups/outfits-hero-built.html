Worth knowing

What changes, and what to look at

Two titlesThe hero is titled "Try this" and the grid "More combos". Both are placeholders, so tell me if you want different words.
Filters moved upOn All, Filters is now at the top right beside New fave, with a sliders icon and the same count badge. It is the same sheet. On Faves it still floats, so the two halves differ until you say otherwise. On very narrow phones the word drops and only the icon shows.
One big ShuffleFixed above the nav on All, and it deals only the hero. The grid stays put. If you are scrolled down, it takes you back up to the hero as it deals. On Faves the same button stays its old size and reorders what you kept.
Only these things are newThe spaces in the hero, the padlock on each, tapping a space to open Filters on it, Filters moving to the header, and the bigger Shuffle. Everything else on the page is as it is today.
The hero is no longer a buttonToday, tapping the hero opens that outfit's page. Now a tap opens Filters, so the way into an outfit's page is the grid below. Tell me if you want a way to keep it on the hero.
The heart overlaps a cornerThe fave heart sits where it does today, top right, so it can touch the top space. I can nudge it if it looks tight to you.
None is on jacket and jumper onlyTop and bottom (or the dress) always have a piece, as the app already requires.
